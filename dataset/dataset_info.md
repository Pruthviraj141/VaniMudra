# Dataset

## Overview
The `dataset` folder acts as an exhaustive alphabetized dictionary mapping for Sign Language representations.

## Structure
*   Contains individual JSON files for every alphabet letter (`a.json` to `z.json`), plus `numbers.json` and a massive `words.txt` master list.
*   Special files like `a_WithHamnosys.json` might represent annotations utilizing the Hamburg Notation System (HamNoSys) for structural sign properties.

## Features
*   Provides granular lookups for individual letters or grouped alphabet words.
*   Serves as the raw, partitioned dictionary source compared to the consolidated `sign_language_data.json` inside the `data` folder.
